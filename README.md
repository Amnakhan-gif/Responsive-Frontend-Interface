# 🚀 LearnSpace — Responsive Learning Platform

A modern and responsive digital learning platform designed to help learners develop practical skills, explore technology, and build their future.

This project was developed as **Project 1 during my Decode Labs Internship Program**, with a focus on responsive frontend development, clean UI design, accessibility, and basic JavaScript interactivity.

## 📌 Project Overview

LearnSpace is a responsive frontend web application created to provide a modern and engaging learning-platform experience.

The interface includes a clean navigation system, hero section, learning dashboard, course information, progress indicators, feature sections, and responsive layouts for different screen sizes.

The project was built using standard web technologies without relying on heavy frameworks.

---

## ✨ Features

- 📱 Fully responsive design
- 💻 Desktop, tablet, and mobile layouts
- 🧭 Responsive navigation with mobile hamburger menu
- 🎯 Hero section with clear call-to-action buttons
- 📚 Course and learning sections
- 📊 Learning progress dashboard
- 📈 Weekly progress indicators
- ⭐ Rating and achievement elements
- ✨ Smooth hover effects and animations
- 🔗 Functional navigation links

- 🎨 Clean and modern user interface
